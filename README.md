# Хранитель Лев: Эхо Древа

Неофициальная браузерная визуальная новелла по мотивам *The Lion Guard*. История начинается спустя несколько недель после финала третьего сезона.

## Запуск

1. Открой папку игры.
2. Дважды нажми `index.html`.
3. Играй.

Интернет, сервер, npm и установка зависимостей не нужны. Все иллюстрации и сценарий находятся в этой папке.

## Управление

- Нажатие на диалоговое окно, `Enter` или пробел: показать реплику полностью или продолжить.
- Клавиши `1`–`4`: выбрать доступный вариант.
- «История»: последние реплики.
- «Настройки»: скорость текста, время QTE, анимации и громкость эффектов.

Прогресс и открытые концовки сохраняются в `localStorage` этого браузера. В настройках доступны экспорт, импорт и удаление сохранения. Пять концовок открываются разными решениями; «Главы» позволяют вернуться к уже достигнутым точкам маршрута.
